# Asynchronous JavaScript Examples

This repository contains a collection of examples demonstrating different concepts of asynchronous programming in JavaScript. Each example is provided with an accompanying HTML file to showcase the functionality in a web browser.

## Introduction

Asynchronous programming is a key feature in JavaScript that allows for non-blocking operations, enabling developers to execute code while waiting for other operations to complete. This repository includes various examples that illustrate the following concepts:

- Callbacks
- Promises
- Async/Await
- IIFE (Immediately Invoked Function Expressions)
- setTimeout
